# Lego aanstuur-app

Een app waarmee kinderen de Lego-etalage kunnen aansturen.

## Structuur

- `client/` React (Vite) frontend
- `server/` Node/Express backend + PostgreSQL
- `database/` SQL-bestanden (tabellen en testdata)

## Starten

1. Kopieer `server/.env.example` naar `server/.env` en vul in.
2. `npm run install:all`
3. `npm run dev`

Frontend: http://localhost:5173 , backend: http://localhost:3000
